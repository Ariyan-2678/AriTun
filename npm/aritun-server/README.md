# aritun-server

AriTun server daemon — run your own tunnel server (self-hosted ngrok alternative).

## Install

```bash
npm install -g aritun-server
```

## Usage

```bash
aritund --domain yourdomain.com --token "$(aritund --gen-token)"
```

Full setup guide: [SETUP.md](https://github.com/Ariyan-2678/AriTun/blob/main/SETUP.md)

See [AriTun](https://github.com/Ariyan-2678/AriTun) for documentation.
